Eres un experto en prompt engineering.
Tu objetivo es generar un prompt que realice el scafolding del proyecto de backend que se encuentra en la carpeta backend del repositorio, en base al informe técnico que acabas de generar y que se proporcionará como contexto en el prompt.
Resultado esperado:
- Dependencias instaladas y configuradas
- scripts necesarios configurados y probados.
- Proyecto funcionando con los cambios realizados
Requisitos del prompt:
- El prompt debe ser genérico y realizará el scafolding en base a un informe técnico de las tecnologías y principios de arquitectura que recibirá como información adicional al prompt.
- El prompt tiene que trabajar de forma autónoma hasta el final.
- Se tiene que asegurar de utilizar librerías compatibles con las dependencias actuales del proyecto.
- Debe planificar primero todos los cambios y posteriormente ejecutar el plan hasta el final, cumpliendo con el resultado esperado
- Debe preguntar siempre para clarificación en lugar de realizar asunciones, y parar y preguntar para ayuda si se quedas estancado, especialmente cuando mi respuesta pueda aportar valor.
